# Generador de Horarios

Proyecto desarrollado en Python para el curso de CampusLands.

El programa permite crear y administrar un horario semanal de materias o actividades.

## Funciones

* Registrar materias o actividades.
* Visualizar el horario semanal.
* Modificar materias o actividades.
* Eliminar materias o actividades.
* Generar un reporte del horario.
* Validar cruces entre horarios.

El programa utiliza un archivo `registro.json` para guardar la información del horario.

## Archivos

```text
main.py
funcion_menu.py
funcion_registro.py
funcion_visualizar.py
funcion_modificar.py
funcion_eliminar.py
funcion_reporte.py
registro.json
```

## Tecnologías

* Python
* JSON
* Librería Tabulate

## Ejecución

Para ejecutar el programa:

```bash
python main.py
```

Al iniciar, se muestra un menú con las diferentes opciones disponibles.
